# Фитнес ниво с дърво на решенията

**Ученик:** Желязко Пламенов Николов, 12. Б клас, № 8  
**Задание:** Тема 8, вариант Б

Проектът определя учебно фитнес ниво по седмични минути тренировки и минути на измислен тест за издръжливост. Дърво на решенията се обучава със синтетични данни и прогнозира една от три категории.

## Стартиране

Използвайте Python 3.11 или по-нов. Отворете терминал в тази папка и изпълнете:

```bash
python -m pip install -r requirements.txt
python main.py
python main.py --predict 145 13
```

Ако командата `python` липсва, използвайте `python3` и в трите команди. Числото 145 означава седмични минути тренировки, а 13 е резултатът на теста в минути. Програмата показва точността, една грешка от проверката и въпросите, през които минава дървото за показаните прогнози.

## Файлове

- `main.py` — обучение, проверка и прогнози.
- `data.csv` — 150 синтетични примера.
- `requirements.txt` — необходима версия на scikit-learn.
- `Pismena_Teoria.pdf` — описание и анализ на проекта.
